# Отчет по заданию 2 (umask)

**Вывод прав при разных масках:**
- С стандартной маской `0022` файл - `644`, каталог - `755`.
- С маской `0077` файл - `600`, каталог - `700`.

**Расчет прав:**
* **Для каталогов** базовые права — `777`. 
  - `777 - 022 = 755`
  - `777 - 077 = 700`
* **Для файлов** базовые права — `666`
  * `666 - 022 = 644`
  * `666 - 077 = 600`

**Почему у файлов нет бита x (выполнение), а у каталогов есть:**
Бит `x` на файле делает его исполняемой программой. А на каталог позволяет входить в него, поэтому по умолчанию включён. 
**Зачем на серверах с конфиденциальными данными ставят umask 077:**
Эта маска отключает права для группы и остальным. Любой новый файл или папка будут доступны только их владельцу.
