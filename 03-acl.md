# ACL

**Вывод getfacl с правилом для user2:**
```
# file: root/secret.txt
# owner: user
# group: user
user::rw-
user:user2:r--
group::---
mask::r--
other::---
```

### Что показал ls -l и почему это важно при аудите:
Команда `ls -l` показывает права `-rw-r-----+`. знак `+` в конце строки прав означает, что на файл назначены расширенные списки контроля доступа (ACL).

### Результаты cat от имени user2:

* До настройки ACL: Отказано в доступе, так как базовые права 600 разрешают чтение только владелбца
* С настроенным ACL: Команда выполняется успешно, лично для пользователя правила.

### Чем ACL удобнее, чем добавление user2 в группу-владельца:
`ACL` позволяет выдать только одному человеку и только на один файл. Добавление в группу может дать доступ другим пользователям.
